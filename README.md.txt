Online Retail Sales Analysis — SQL & Power BI
О проекте
Учебный аналитический проект на основе данных интернет-магазина Online Retail. Целью является исследовать динамику продаж, определить ключевые рынки и товары, изучить клиентскую активность и проанализировать отрицательные транзакции.
В рамках проекта данные были обработаны с помощью SQL в PostgreSQL, а результаты представлены в интерактивном отчёте Power BI.

Тип проекта: Exploratory Data Analysis (EDA), BI-аналитика
Роль: Дата Аналитик / BI аналитик (учебный проект)
Статус: завершённая базовая версия

Бизнес-задачи
- Проанализировать динамику выручки и количества заказов
- Определить товары с наибольшей выручкой
- Исследовать географическое распределение продаж
- Оценить клиентскую активность и повторные покупки
- Выделить отрицательные транзакции и потенциальные аномалии
- Сформулировать бизнес-выводы и рекомендации на основе данных
Инструменты:
- PostgreSQL — хранение, очистка, преобразование и анализ данных
- SQL — фильтрация, агрегации, группировки, условная логика и аналитические запросы
- Power BI Desktop — визуализация данных и создание интерактивного отчёта
- DAX — расчёт аналитических показателей и KPI
Источник данных:
Использован датасет Online Retail от UCI Machine Learning Repository.
Датасет содержит транзакции интернет-магазина, зарегистрированные в период с 1 декабря 2010 года по 9 декабря 2011 года.
Основные поля:
- InvoiceNo — номер счёта
- StockCode — код товара
- Description — описание товара
- Quantity — количество единиц товара
- InvoiceDate — дата и время транзакции
- UnitPrice — цена за единицу
- CustomerID — идентификатор клиента
- Country — страна покупателя

Этапы работы:
1. Подготовка данных
- Импорт исходных данных в PostgreSQL
- Создание промежуточной staging-таблицы
- Преобразование текстовых значений в числовые и временные типы данных
- Обработка пустых строк и пропущенных идентификаторов клиентов
- Расчёт суммы строки транзакции: quantity × unit_price
- Проверка отрицательных количеств, нулевых цен и отрицательных сумм
2. SQL-анализ
С помощью SQL выполнены:
- анализ выручки и заказов по месяцам
- рейтинг товаров по выручке и количеству проданных единиц
- анализ продаж по странам
- расчёт среднего и медианного чека
- анализ повторных покупок и клиентской активности
- исследование отрицательных транзакций
- проверка потенциально аномально крупных заказов и анализ чувствительности результатов к их исключению

Для дальнейшего анализа создано представление «online_retail_sales», которое классифицирует положительные товарные продажи отдельно от отрицательных транзакций и служебных позиций.

3. Расчёт метрик в Power BI
Созданы меры DAX:
- Revenue — выручка от положительных товарных продаж
- Orders — количество уникальных счетов в положительных товарных продажах
- Units Sold — количество проданных единиц товара
- Average Order Value — средняя выручка на один учтённый счёт
- Customers — количество идентифицируемых клиентов
- Repeat Customers — количество клиентов с двумя и более учтёнными счетами
- Repeat Customer Rate — доля клиентов с повторными покупками;
- Return Lines и Return Amount — показатели отрицательных строк по счетам с префиксом C

4. Визуализация в Power BI
Отчёт состоит из четырёх страниц:
1. Обзор продаж:
- ключевые KPI
- динамика выручки по месяцам
- топ-10 товаров по выручке
2. География продаж:
- распределение выручки по странам
- топ-10 стран по выручке
- таблица ключевых показателей по странам
3. Анализ клиентов:
- количество идентифицируемых клиентов
- показатели повторных покупок
- топ-10 клиентов по выручке
- таблица клиентских показателей
4. Анализ возвратов:
- количество отрицательных строк по счетам с префиксом C
- абсолютная сумма таких строк
- динамика по месяцам
- детализация отрицательных транзакций

Ключевые результаты:
- Общая выручка от положительных товарных продаж по принятой методике составила около 10,27 млн в денежных единицах исходного датасета.
- На Великобританию пришлось около 85,2% этой выручки.
- Максимальная месячная выручка за полный календарный месяц наблюдалась в ноябре 2011 года и составила около 1,46 млн.
- Количество учтённых счетов в ноябре 2011 года достигло 2 751.
- Среди лидеров по выручке можно выделить REGENCY CAKESTAND 3 TIER и PAPER CRAFT, LITTLE BIRDIE.
- У приблизительно 24,9% строк отсутствует идентификатор клиента, что ограничивает полноту клиентского анализа.
- Обнаружен необычно крупный заказ товара PAPER CRAFT, LITTLE BIRDIE на 80 995 единиц с суммой строки 168 469,60. Он был выделен для дополнительной проверки, а не автоматически удалён из данных.



Бизнес-выводы и рекомендации:
1.	Высокая концентрация продаж в Великобритании. Стоит исследовать возможности развития других рынков, одновременно учитывая риски зависимости от основного рынка.
2.	Рост продаж к концу года. Ноябрь показал максимальную месячную выручку. Для проверки сезонности необходимо сравнить аналогичные периоды за несколько лет.
3.	Необходимость проверки крупных заказов. Аномально большие значения могут существенно влиять на рейтинг товаров и общие показатели. Их следует проверять по контексту транзакций, не исключая автоматически.
4.	Ограничения клиентского анализа. Пропуски в CustomerID снижают полноту оценки повторных покупок. Улучшение качества клиентских данных повысило бы надёжность метрик удержания.
5.	Разделение продаж и отрицательных транзакций. Возвраты, корректировки и служебные операции необходимо учитывать отдельно, чтобы не искажать показатели товарных продаж.
Ограничения анализа:
- Данные охватывают примерно один год; декабрь 2011 года представлен только до 9 декабря и является неполным.
- Не у всех транзакций указан идентификатор клиента.
- Наличие префикса C и отрицательного количества помогает выделить потенциальные возвраты, но не подтверждает фактическое движение денежных средств.
- Необычно крупные заказы требуют дополнительной проверки. Их корректность нельзя определить только по величине.
- Валюта явно не указана в используемых полях, поэтому денежные показатели приведены без обозначения валюты.
- Выводы описывают наблюдаемые закономерности и не доказывают причинно-следственные связи.
